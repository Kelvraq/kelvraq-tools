# kelvraq tools

Локальный файловый каталог для Windows на Tauri и Rust.

## Возможности

- Навигация по реальным папкам и дискам.
- Закрепление файлов и папок, собственные разделы.
- Отдельный каталог приложений: EXE и ярлыки Windows.
- Превью изображений с размытой подложкой.
- Поиск в текущей папке и по именам на локальных дисках, список и плитки.
- Просмотр видео прямо в карточке: пауза, звук и перемотка.
- Создание папок, переименование, отправка в корзину с подтверждением.

## Разработка

Требуются Node.js, Rust MSVC, Visual Studio C++ Build Tools, Windows SDK и WebView2 Runtime.

```sh
npm ci
npm run dev
```

## Проверки

```sh
npm test
cargo test --release --manifest-path src-tauri/Cargo.toml
npm run format
```

## Сборка

```sh
npm run build
```

Исполняемый файл: `src-tauri/target/release/kelvraq-tools.exe`.

```text
web/
```

## Данные

Настройки сохраняются в `%APPDATA%\kelvraq-tools\catalog.json`. Добавление и удаление ссылок в каталоге не меняет оригинальные файлы. Переименование, создание папок и отправка в корзину работают с файловой системой.

Раздел «Приложения» запускает выбранные пользователем EXE и ярлыки Windows. Удаление из раздела не удаляет установленную программу.

## Ограничения

Поиск «Везде» обходит локальные диски без индекса, пропускает недоступные каталоги и не следует по ссылкам и точкам соединения. Минимум 2 символа, до 2000 результатов; содержимое документов не индексируется. Превью доступны для PNG, JPEG, WEBP и BMP до 16 МБ. Встроенного просмотра 3D-моделей нет.

Поддержка видео зависит от кодеков системного WebView2. Одновременно воспроизводится одно видео.
